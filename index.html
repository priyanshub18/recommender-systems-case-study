The Formal Optimization Problem

Balancing catalog utility against strict inference latency and presentation redundancy.

OBJECTIVE FUNCTION

Given user u ∈ U, catalog I (|I| > 107), and real-time context vector xu,c:

S* = argmax|S|=K ∑i ∈ S U(u, i, c) − λ Ω(S)
Interactive Mathematical Components
• U(u, i, c): Expected utility (Watch Probability × Expected Stream Duration)
• Ω(S): Redundancy penalty (e.g. pairwise genre/actor similarity inside slate S)
• λ: Exploration / Diversity trade-off hyperparameter
The 15ms Latency Budget

An exhaustive forward pass of a 100M parameter model across 10M titles takes ~4,500ms. Production architectures enforce a strict sub-15ms deadline:

1. Gateway & Auth (2ms) 13%
2. Candidate Retrieval MIPS (4ms) 27%
3. Deep Neural Reranker (7ms) 47%
4. Bandit Artwork & Dedup (2ms) 13%

Offline Bias: Inverse Propensity Scoring

Correcting presentation bias in log click data so offline ranking benchmarks reflect true relevance.

DEBIASED EVALUATION
The Position Bias Dilemma

Position 1 receives 400% more clicks simply because users read top-to-bottom, regardless of true quality. Evaluating models on raw clicks reinforces self-fulfilling feedback loops.

R̂IPS = 1/|D| ∑(u,i) ∈ D [ yui × cui / P(Oui=1 | posi) ]
• yui: Binary feedback (click or stream ≥ 2 min)
• P(Oui=1 | pos): Examination propensity at rank position
• cui: Counterfactual weight correcting observational bias
Examined Click-Through Probability Across Ranks
Comparing Naive Observed CTR vs Unbiased Examination Propensity:
Rank 1 (Top Hero) Observed: 42% • Propensity: 0.88
Rank 3 (Row Center) Observed: 18% • Propensity: 0.42
Rank 10 (Far Right) Observed: 4% • Propensity: 0.12
• IPS mathematically guarantees unbiased off-policy A/B risk reduction.
