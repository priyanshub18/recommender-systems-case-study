# How Netflix Decides What You Watch Next: A Graph Theory View

An animated, step-by-step slide deck for a college talk. It explains recommender systems with basic graph theory, using a small Netflix example.

**Live:** https://priyanshub18.github.io/recommender-systems-case-study/

6. More paths mean a stronger recommendation (and the B·Bᵀ·B matrix view)
7. Random walks / Personalized PageRank (live simulation)
8. Cold start: a new show with no viewers
9. The full pipeline
10. Limitations: popularity bias, filter bubble, privacy
11. Key takeaways, references, questions
